Test programs from Tom Seddon's b2 emulator
(https://github.com/tom-seddon/b2, folder `etc`; GPL v3, "freely available
and distributable" per its README), written by Tom Seddon, Chris Evans,
Kevin Edwards, David Banks, Kieran Connell, Coeus and Taliadon.

BeebLink volumes: each BBC file has a `.inf` with its name and load / exec
addresses.  `T.*` are test programs, `O.*` their output recorded on a
real BBC Micro.  `tests/b2_tests.py` runs them in AdaBeeb.
